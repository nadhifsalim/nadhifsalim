I am an Electrical Engineering with a specialized focus on hardware-level programming, microcontroller architectures, and digital logic. My core technical interest lies at the intersection of embedded systems and chip design. I am actively studying hardware description languages and open-source EDA toolchains with the long-term objective of designing, verifying, and fabricating custom integrated circuits. 

### Current Academic & Technical Focus

* **Digital IC Design & RTL Synthesis:** Studying hardware description languages (Verilog, SystemVerilog, SpinalHDL) and utilizing open-source EDA tools (Yosys, Verilator, Icarus Verilog) for simulation and logic synthesis within Linux environments.
* **Embedded Systems Architecture:** Exploring microprocessor architectures by transitioning from bare-metal C programming on 8-bit AVR microcontrollers to 32-bit ARM Cortex-M (STM32) systems and RTOS integration.
* **Hardware Development:** Translating logical designs into physical implementations, including schematic capture, PCB routing, and analyzing hardware-software interfaces.
