# Hi there, I'm Nadhif 👋

### Electrical Engineering Undergraduate | Embedded Systems & Digital IC Design

I am an Electrical Engineering student fascinated by how computing systems operate down to the silicon level. My technical focus sits at the intersection of **embedded firmware engineering** and **integrated circuit (IC) design**. 

Whether I am writing bare-metal register-level code for microcontrollers or describing digital logic in RTL, I enjoy working across different levels of hardware abstraction—from high-level frameworks and Hardware Abstraction Layers (HAL) all the way down to logic gates and custom PCBs. My long-term goal is to design, verify, and tape out custom open-source silicon.

---

### Current Technical Focus

| Domain | What I'm Working On |
| :--- | :--- |
| **Digital IC Design & RTL** | Writing synthesizable hardware in **Verilog**, and running simulation & logic synthesis using open-source Linux EDA flows (**Yosys, Icarus Verilog**). |
| **Embedded Firmware** | Exploring microprocessor architectures across abstraction layers—from bare-metal C on 8-bit **AVR** to 32-bit **ARM Cortex-M (STM32)** and **FreeRTOS** multi-tasking on **ESP32**. |
| **Hardware & PCB Design** | Translating logical schematics into physical boards using **KiCad** and **easyEDA**, focusing on clean PCB routing, sensor integration, and hardware-software interfaces. |
